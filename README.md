# Missione Matrimonio

Raccolta delle idee condivise nel gruppo WhatsApp del matrimonio, pubblicata su GitHub Pages.

Il sito è un unico file statico, `index.html`, senza build né dipendenze esterne: i dati sono
incorporati nella pagina in un blocco JSON (`<script id="data" type="application/json">`).
Per aggiornarlo basta sostituire `index.html` con la nuova versione e fare commit su `main`;
l'indirizzo pubblico resta lo stesso.
